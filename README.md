
# EcoLanka - Ecotourism Management System

EcoLanka is a centralized web-based platform dedicated to eco-friendly, sustainable travel in Sri Lanka. It connects tourists, service providers, and conservation authorities into a single digital hub to promote responsible tourism, support local communities, and raise awareness for biodiversity conservation. 

**Key Features**
* **Centralized Discovery:** Browse and filter verified eco-friendly destinations and activities across Sri Lanka.
* **Smart Recommendations & AI Chatbot:** Get personalized travel suggestions and 24/7 assistance through an AI-powered recommendation engine.
* **Live Environmental Insight:** Integrated Google Maps, real-time weather, and biodiversity APIs provide essential data for responsible travel decisions.
* **Conservation Engagement:** View and participate in local environmental donation campaigns and eco-projects.
* **Role-Based Access & Dashboards:** Secure authentication for tourists, with dedicated analytics and management dashboards for administrators and system managers.

**Technology Stack**
* **Frontend:** React.js, Tailwind CSS, Zustand / React Query, Chart.js
* **Backend:** Node.js, Express.js (RESTful API architecture)
* **Database:** MySQL / PostgreSQL
* **Infrastructure & Tools:** GitHub Actions (CI/CD), Docker, Nginx, deployment via AWS / Vercel / Railway
