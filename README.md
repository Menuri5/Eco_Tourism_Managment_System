# Eco Tourism Management System

## About the Project

The Eco Tourism Management System is a web-based system designed to promote and manage eco-tourism activities and destinations. The system helps tourists discover eco-friendly destinations, activities, guides, and donation campaigns while supporting sustainable tourism.

## Main Features

* Tourist registration and login
* Explore eco-tourism destinations
* Search and filter destinations
* View destination details
* Find and contact tour guides
* Favourite destinations
* Ratings and reviews
* Eco-tourism activities
* Donation campaigns
* Admin dashboard
* Manage destinations, categories, guides, and users
* System manager dashboard
* Analytics and usage monitoring
* Environmental data monitoring
* System health monitoring
* API integration management
* AI chatbot support

## User Roles

### Tourist

Tourists can register, explore destinations, view guides, participate in eco-tourism activities, add favourites, provide reviews, and support donation campaigns.

### Admin

The admin can manage destinations, categories, guides, users, reviews, and donation campaigns through the admin dashboard.

### System Manager

The system manager can monitor system health, manage system settings, view analytics, monitor tourist usage, and manage system data.

## Technologies Used

* React.js
* JavaScript
* Tailwind CSS
* Node.js
* Express.js
* MySQL
* REST API

## Project Goal

The main goal of this project is to provide a user-friendly digital platform that connects tourists with eco-friendly tourism experiences while supporting environmental protection and sustainable tourism in Sri Lanka.
